# SPBSTUParse 📊

SPBSTUParse — это Python-скрипт для получения и обработки конкурсных списков абитуриентов СПбПУ (Политех).  
Он автоматически загружает данные по выбранной программе и квоте, обрабатывает их и сохраняет в Excel-таблицу.

---

## 🚀 Возможности

- Получение списка абитуриентов через API СПбПУ
- Парсинг данных по выбранной программе и квоте
- Обработка данных студентов:
  - ЕГЭ баллы
  - индивидуальные достижения
  - приоритет
  - согласие на зачисление
- Экспорт в Excel (.xlsx)

---

## 🧠 Как работает

1. Пользователь вводит:
   - код программы
   - номер квоты

2. Скрипт:
   - загружает данные (get_list)
   - преобразует JSON → объекты Student
   - обрабатывает баллы
   - сохраняет результат в Excel

---

## ▶️ Запуск

pip install requirements.txt

python main.py

---

## 📥 Использование

Напишите код программы: 09.03.03 (Пример)
Напишитие номер вашей квоты:
1 (Бюджетная основа)
2 (Контракт)
3 (Особое право)
4 (Отдельная квота)
5 (Целевой приём)

После выполнения создаётся файл:

Политех. <номер программы>. <квота>.xlsx

## 🧩 Основная логика

parseStudents:
- преобразует JSON → объекты Student
- группирует баллы по предметам

save_to_excel:
- использует openpyxl
- создаёт Excel-файл
- записывает данные построчно
